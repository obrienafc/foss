## Version Control

- [Bitbucket](https://bitbucket.org/) - Git hosting, free for up to 5 users; community licences for open source projects.
- [Codeberg](https://codeberg.org/) - Free as in freedom Git hosting for open source, run by a nonprofit association. Includes Codeberg Pages.
- [GitHub](https://github.com/) - Free public and private repositories.
- [GitLab](https://about.gitlab.com/solutions/open-source/) - Free repositories and CI/CD. The GitLab for Open Source programme gives qualifying projects top-tier features. - request needed

## Project Hosting

- [NuGet](https://www.nuget.org/) - .NET package hosting.
- [PythonAnywhere](https://www.pythonanywhere.com/) - Hosting for Python web apps. - has limits
- [SourceForge](https://sourceforge.net/) - Git, Mercurial and SVN project hosting with downloads.
- [GitHub Pages](https://pages.github.com/) - Static site hosting straight from a repository.

## Public Cloud

- [DigitalOcean](https://www.digitalocean.com/open-source/credits-for-projects) - Yearly cloud credits for open source projects, tiered by project size. - request needed
- [OpenShift](https://www.openshift.com/grants/) - Resource grants for open source and non-profit projects. - request needed
- [Heroku](https://www.heroku.com/open-source-credit-program/) - Open Source Credit Program: monthly platform credits for 12 months. - request needed
  - _Changed:_ The free dyno tier was removed in November 2022. Open source projects can apply for credits instead.
- [Vercel](https://vercel.com/open-source-program) - Hobby tier with static and serverless hosting and a global CDN, plus an open source sponsorship programme. - request needed
- [Netlify](https://www.netlify.com/open-source/) - Open Source plan with Pro features for qualifying projects. - request needed
- [Cloudflare Pages](https://pages.cloudflare.com/) - Static and full-stack hosting on Cloudflare's network, generous free tier.

## Documentation

- [GitBook](https://www.gitbook.com/) - Documentation platform, free for qualifying open source projects. - request needed
- [Read the Docs](https://readthedocs.org/) - Builds, versions and hosts your docs. Free for open source (ad-supported).
- [Atlassian Confluence](https://www.atlassian.com/software/views/open-source-license-request) - Team wiki. Free Cloud licence for open source projects. - request needed

## Continuous Integration

- [GitHub Actions](https://github.com/features/actions) - CI/CD built into GitHub. Free for public repositories on standard runners.
- [AppVeyor](https://www.appveyor.com/) - CI for Windows, Linux and macOS, free for open source.
- [Azure Pipelines](https://learn.microsoft.com/azure/devops/pipelines/licensing/concurrent-jobs) - Cloud-hosted pipelines for Linux, macOS and Windows. Free parallel jobs for public projects. - request needed
  - _Changed:_ Since 2021 the free open source grant must be requested with a form.
- [Bitrise](https://bitrise.io/) - CI/CD for mobile apps. Public apps get Developer plan features free.
- [CircleCI](https://circleci.com/open-source/) - CI/CD with a free plan and extra build credits for open source.
- [Codecov](https://about.codecov.io/) - Code coverage reporting, free for open source. Now part of Sentry.
- [Coveralls](https://coveralls.io/) - Code coverage history, free for open source.
- [DeployHQ](https://www.deployhq.com/) - Continuous deployment from Git. DeployBot has merged into DeployHQ. - request needed
- [Knapsack Pro](https://knapsackpro.com/) - Splits your test suite across parallel CI nodes. - request needed
- [Sauce Labs](https://saucelabs.com/) - Cross-browser and mobile testing, free accounts for qualifying open source. - request needed
- [Scrutinizer](https://scrutinizer-ci.com/) - CI and code analysis for GitHub and Bitbucket, free for open source.
- [Semaphore](https://semaphore.io/open-source) - Hosted CI/CD, free for open source. The platform itself is open source (Apache 2.0) since 2025.
- [TeamCity](https://www.jetbrains.com/community/opensource/) - JetBrains CI server, free under the open source support programme. - request needed - **strict rules**
- [Travis CI](https://www.travis-ci.com/) - Hosted CI for GitHub. - request needed
  - _Changed:_ travis-ci.org closed in 2021 and unlimited free builds ended. Open source projects can request OSS credits.
- [Atlassian Bamboo](https://www.atlassian.com/software/bamboo) - Self-hosted CI/CD.
  - _Changed:_ Bamboo is now Data Center only, and Atlassian's open source licences mainly cover Cloud products. Check eligibility before relying on it.
